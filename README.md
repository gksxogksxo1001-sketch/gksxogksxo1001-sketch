## 👨‍💻 "사용자가 즐겁고, 시스템이 편안한 서비스를 만듭니다."

기술은 사람들의 일상을 더 즐겁고 편리하게 만들 때 가장 가치 있다고 믿습니다.  
화면 앞에서는 **"와, 이거 재밌고 편리하다!"** 소리가 나오는 직관적인 UX를 선사하고,  
보이지 않는 화면 뒤에서는 **트랜잭션 하나, 데이터 정합성 하나까지 빈틈없이 돌아가는 단단한 백엔드**를 구축합니다.

- 🎮 **아이디어를 끝까지 완성하는 실행력**: 웹 브라우저에서 돌아가는 턴제 RPG 게임부터 스마트폰 속 소셜 지도 앱까지 기획·설계·배포를 직접 해냅니다.
- 🧱 **데이터 안전 제일주의**: 재화 결제, N빵 정산, 뽑기(가챠) 등 돈과 데이터가 오가는 로직은 `@Transactional`과 원자성으로 철저히 보호합니다.
- ⚡ **유연한 모던 풀스택**: 백엔드(`Java`, `Spring Boot 3`)의 묵직한 안정성과 프론트엔드(`Next.js 16`, `React 19`, `Tailwind v4`)의 빠른 인터랙션을 자유롭게 엮어냅니다.

> *"별도 설치 없이 웹 브라우저만 켜면 바로 펼쳐지는 고전 무협의 세계!"*

- **🎮 직접 즐길 수 있는 재미 포인트**:
  - **마을 2D 탐험 (WASD 조작)**: 레트로 게임처럼 키보드로 마을을 거닐며 대장간, 주점(소환소), 던전 포탈과 인터랙션!
  - **스피드 기반 턴제 배틀**: 단순 자동 사냥이 아닌, 캐릭터의 민첩도(Speed)에 따라 턴 순서가 계산되고 감전·빙결 등 상태이상을 활용하는 전략 전투.
  - **두근두근 주점 가챠 & 영웅 육성**: 4인 파티 편성, 경지 상승, 무기 강화 시스템.
- **⚙️ 기술적 고민 & 해결**:
  - 가챠 소환이나 전투 보상 지급 시 네트워크 오류가 나도 재화가 유실되거나 복사되지 않도록 `@Transactional` 원자적 트랜잭션 보장.
  - 보안 강화를 위해 회원 가입/아이디 찾기 시 이메일 마스킹(`ab***@gmail.com`) 및 Google Mail API 연동 서신 발송.

### 02. 📱 [HANS (한스) — 위치 기반 모임 & 스마트 N빵 정산 소셜 앱](https://github.com/gksxogksxo1001-sketch/SNS)
> *"지도 위에서 모이고, 실시간 톡하고, 영수증 N빵 정산까지 깔끔하게!"*

<div align="center">

[![Repository](https://img.shields.io/badge/GitHub_저장소-HANS_보러가기_👉-238636?style=for-the-badge&logo=github)](https://github.com/gksxogksxo1001-sketch/SNS)
![Next.js 16](https://img.shields.io/badge/Next.js_16-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)
![React 19](https://img.shields.io/badge/React_19-61DAFB?style=for-the-badge&logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript_5.0-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase_Firestore-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)
![TailwindCSS v4](https://img.shields.io/badge/TailwindCSS_v4-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)

</div>

- **💡 기획 의도**: 친구나 소모임 회원들과 만날 때 가장 많이 겪는 **"오늘 어디서 만나지?"**와 **"헤어질 때 돈 계산 어떻게 하지?"**를 하나의 앱으로 풀어냈습니다.
- **✨ 주요 기능 & 사용자 경험**:
  - **내 주변 핫플레이스 지도 핀 (Google Maps 연동)**: 지도를 보며 내 주변 번개 모임 장소와 유저들의 생생한 위치 피드 탐색.
  - **스마트 더치페이 정산기 (Settlement)**: 총 지출 내역과 영수증을 등록하면 인원수대로 1/N 자동 분할 및 정산 상태 추적.
  - **실시간 소통 & 24시간 스토리**: 인스타그램 감성의 스토리 업로드 및 Firestore 기반 끊김 없는 1:1 실시간 채팅 & 토스트 알림.
- **⚙️ 기술적 고민 & 해결**:
  - 최신 `Next.js 16 (App Router)`과 `React 19`의 Server/Client 컴포넌트 분리로 빠른 로딩 속도 달성.
  - 복잡한 정산 상태 및 유저 알림 상태를 `Zustand 5.0` 경량 상태 라이브러리로 최적화하여 렌더링 낭비 방지.

- **💡 기획 의도**: 단순한 정적 웹페이지가 아니라, 실제로 유저가 가입하고 댓글로 소통하며 문의를 주고받을 수 있는 동적 풀스택 웹 서비스를 지향했습니다.
- **✨ 주요 기능 & 사용자 경험**:
  - **프로젝트 갤러리 쇼케이스**: 이미지 업로드 파이프라인을 거친 스크린샷과 프로젝트 상세 설명 열람.
  - **기술 토론 게시판**: 페이징 및 키워드 검색, 질문과 답변을 주고받는 계층형 댓글(CRUD) 시스템.
  - **원클릭 다이렉트 문의 메일**: 방문자가 웹에서 글을 남기면 Google SMTP를 통해 개발자의 이메일로 알림이 즉시 발송되는 창구.
- **⚙️ 기술적 고민 & 해결**:
  - Spring Security를 연동하여 관리자(ROLE_ADMIN)와 일반 사용자의 권한을 분리, 포트폴리오 등록/수정/삭제 권한 엄격히 보호.
  - MyBatis SQL 매핑을 통해 복잡한 검색 쿼리 및 통계 데이터의 튜닝 용이성 확보.
