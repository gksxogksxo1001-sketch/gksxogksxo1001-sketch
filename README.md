## ☕ About Me: "사용자가 머물고 싶은 편안한 서비스를 만듭니다"

따뜻하고 직관적인 사용자 경험(UX)과, 보이지 않는 곳에서 묵묵히 돌아가는 단단한 백엔드 아키텍처를 지향합니다.  
**일상의 번거로움을 해결하는 소셜 서비스**, **자취생을 위한 스마트 식비·냉장고 비서**, **수험생을 위한 모바일 CBT 학습관**처럼 사람들의 손끝에 닿는 실질적인 가치를 만들어갑니다.

- 🌿 **누구나 쉽게 다가오는 편안한 UX**: 복잡한 기능도 사용자가 직관적으로 이해하고 기분 좋게 사용할 수 있도록 디자인하고 구현합니다.
- 🛠️ **탄탄한 데이터 정합성 & 아키텍처**: 영수증 1/N 정산, 오픈 API 영양소 분석, 실시간 1:1 메시징까지 데이터의 흐름을 꼼꼼하게 관리합니다.
- 💡 **문제를 서비스로 풀어내는 집념**: 불편함을 발견하면 기획부터 프론트엔드·백엔드·배포까지 원스톱으로 완성해냅니다.
