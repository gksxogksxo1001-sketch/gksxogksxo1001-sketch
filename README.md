## 👨‍💻 About Me

> **"복잡한 비즈니스 로직을 단순하고 명확하게 모델링하고, 사용자에게 쾌적한 인터랙션을 선사합니다."**

- 🧱 **데이터 정합성과 확장성**: 다중 사용자 환경에서도 트랜잭션 무결성과 데이터 일관성을 보장하는 아키텍처를 추구합니다.
- ⚡ **모던 풀스택 역량**: `Spring Boot 3` 기반의 강력한 서버 설계와 `Next.js 16 (React 19)`를 활용한 반응형 프론트엔드를 빈틈없이 연결합니다.
- 🎯 **도메인 중심의 문제 해결**: 턴제 RPG 연산 엔진부터 실시간 위치 피드 & 소셜 정산 시스템까지, 서비스 특성에 최적화된 설계를 직접 구현해왔습니다.
